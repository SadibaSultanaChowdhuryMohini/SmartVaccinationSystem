# 🇧🇩 Smart Vaccination Tracking System

A centralized, automated immunization monitoring registry designed to calculate and track medical compliance according to the Bangladesh EPI program.

## 🚀 Key Features Built
* **Dynamic Calendar Logic:** Automatically references child date of birth records to construct a 13-dose target application matrix.
* **Proactive Notification Hub:** Front-end status tracking engine displaying `⚠️ ACTION DUE` reminders and clinical checkup parameters.
* **Parent Portal:** Secure interface allowing registration configurations and immediate record updates.

## 🛠️ Tech Stack Employed
* **Backend Framework:** Django 
* **Database Management:** SQLite3 Relational Core
* **Frontend Presentation:** HTML5, CSS3 Architecture
